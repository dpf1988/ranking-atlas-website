# New Research Landing Page: Publish Checklist

Run through before every new page under `/resources/`.

## 1. RelatedResearch component
- [ ] 3 curated sibling studies passed as items (not the same three every time)
- [ ] Each item has `title`, `description`, and `href`

## 2. Body links (minimum 3 contextual internal links)
- [ ] Homepage attribution: link "Ranking Atlas" to `/` in the intro or overview
- [ ] `/resources/citation-equity` linked in methodology or closing section
- [ ] One topically related sibling resource linked in body prose

## 3. Inbound link from existing page
- [ ] Add one contextual body link from the most relevant existing resource or blog page pointing to this new page

## 4. Link format
- [ ] All hrefs use clean paths: no trailing slash, no `.html` suffix

## 5. Build
- [ ] `npm run build` passes with no errors
- [ ] Page count is previous count + 1
